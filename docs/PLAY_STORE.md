## 2. Create the app in Play Console ⚠️

1. Pay the one-time developer registration fee and verify the account (identity, and a phone/address for personal accounts).
2. *Create app*: name **نور - القرآن والصلاة والأذكار** (default language Arabic), *App*, *Free*, accept the declarations.
3. Check the package name is free: the bundle uses `app.noor.noor`. If another developer already owns it, change `applicationId` in `android/app/build.gradle.kts` (and the Firebase apps) **before** the first upload — it cannot change afterwards.
4. New personal accounts must first run a **closed test** with the required number of testers for the required number of days before production access is granted (at the time of writing: 12 testers, 14 days — confirm the current rule in the console). Start with *Internal testing* to try the install.

## 5. Data safety form

Is any data collected or shared? **Collected: yes (optional). Shared: no** (Firebase acts as our service provider, which Google does not count as sharing). All data is **encrypted in transit**. Users **can request deletion** (in-app, and the URL above).

| Data type | Collected | Why | Optional |
|---|---|---|---|
| Personal info → Email address | Yes, only if the person creates an account | App functionality, account management | Yes |
| Personal info → Name | Yes, display name for the account | Account management | Yes |
| Personal info → User IDs | Yes (Firebase user id) | App functionality, account management | Yes |
| App info and performance → Crash logs, Diagnostics | Yes, only if the person agrees on the in-app card | Analytics (fixing crashes) | Yes |
| Device or other IDs | Yes: Crashlytics installation id, only with crash reports on | Analytics | Yes |
| Location → Approximate / Precise | **Declare as collected (conservative):** the phone’s own map service may receive the coordinates to name the city. No NOOR server ever receives them | App functionality | Yes |
| Everything else (contacts, messages, photos and files, calendar, health, financial, web history, audio, app activity) | **No** | — | — |

The Google profile photo URL (if Google/Apple provide one) is stored only in the person’s Firebase profile and shown in *My account*.

## 6. Permission declarations ⚠️

Paste these when the console asks (English, reviewers read English).

- **Exact alarms (`SCHEDULE_EXACT_ALARM`)** — “NOOR alerts the user at the exact start of each of the five daily Islamic prayers. The times change every day and with the user’s location, so alerts are scheduled as exact alarms; a delay of several minutes defeats the purpose. Alerts are only scheduled for prayers the user has switched on.”
- **Foreground service: media playback (`FOREGROUND_SERVICE_MEDIA_PLAYBACK`)** — “The app plays Quran recitations and Quran radio. A media-playback foreground service with a playback notification and lock-screen controls keeps the audio playing when the user leaves the app.” The console may ask for a short screen recording: open *Audio*, start a recitation, press home and show the notification and lock-screen controls.
- **Location (`ACCESS_FINE_LOCATION`, `ACCESS_COARSE_LOCATION`)** — foreground only: prayer times and Qibla direction from the user’s position. Never used in the background.
- `POST_NOTIFICATIONS` (adhan alerts), `RECEIVE_BOOT_COMPLETED` (re-schedule alerts after a restart), `WAKE_LOCK` and `VIBRATE` (audio and alert vibration) need no form. `USE_BIOMETRIC`/`USE_FINGERPRINT` are added by a sign-in library; NOOR does not use biometrics.

## 8. After the first upload

1. *Setup → App integrity*: copy the **App signing key certificate** SHA-1/SHA-256 and register them in Firebase, otherwise Google sign-in fails in the store build. Also register the upload key above for local release builds:
   ```bash
   firebase apps:android:sha:create 1:849515368017:android:f641355b92e8c2cd00f270 <SHA-1 without colons> --project noor-app-alaa-4829
   firebase apps:sdkconfig android 1:849515368017:android:f641355b92e8c2cd00f270 --project noor-app-alaa-4829 > android/app/google-services.json
   ```
2. Restrict the Firebase API keys to the package name and SHA-1 (see [FIREBASE.md](FIREBASE.md)).
3. Enable **Sign in with Apple** only matters for iOS; nothing to do for Play.
